# 【比例比例阿婆主，给特哈勃小萌新】

## 1 - 成为一名正式的UP主

### 1.1 - 恭喜09年小伙喜提14年主机

早在2020年暑假，大概是7月23日，我注册了B站账号。后来到2022年年初，我开始用手机发一些转载的视频（所以在B站创作中心里显示的我成为UP主的时间就是那个时候了，但其实不是的）。

直到2024年初，继上篇G455笔记本奔西之后，我又得到了一台老台式机（不要问我为什么老是能得到一些清朝东西……），在我刚拿到它的时候，配置是这样的：

| 硬件  | 配置                                 |
| :-- | :--------------------------------- |
| 主板  | 映泰 BIOSTAR B85MG                   |
| CPU | Intel® Core™ i3-4150 @ 3.50GHz     |
| 内存  | Kingston DDR3 8G 1600MHz           |
| 显卡  | 耕升 NVIDIA® GeForce™ GT740 2G GDDR5 |
| 硬盘  | 西数 WD10EZEX 1.0TB                  |
| 电源  | 鑫谷 Segotep 400W                    |
| 其他  | 华硕 ASUS DVD-ROM 光驱                 |
| 系统  | Windows 7 旗舰版                      |

这个配置应该是2013或2014年的主流轻奢配置，10年后的2024年，这个配置肯定是有点力不从心了。但是，这个配置怎么说也要比以前那个老G455强得多，既然性能上去了，我也可以摸到一点剪视频的门槛了。

后来按照惯例，我上手就把这个系统给重装了，重装成Windows 10 专业版 22H2。简单的把玩了它几天之后，我就开始想干正事了。

### 1.2 - 正式的“初来乍到”

在之前的文章中，我有说到过，我在2020年的时候在抖音发过视频，虽然都是很弱智的视频啊，当时剪辑技术也不高，或者说压根儿就不怎么会剪辑，但是，基本的剪辑技术多少我也是会点的。在这个电脑上装上了剪映专业版后，简单上手熟悉一下之后，我就用我那种依旧不成熟的剪辑手法，造出了一个也算是我在B站上发的第一个正式视频：

![Snipaste_2026-08-11_16-34-18.png](https://img.danevan.top/image/pic/Snipaste_2026-08-11_16-34-18.png)

[一个视频教会你！将N万字的小说压缩成仅仅几张A4纸！](https://www.bilibili.com/video/BV16y421a74q/)

其实这个视频发出去也反响平平，第一是我这个号没有任何的粉丝基础，所以新号开号都很难嘛；第二就是这个剪辑技术，还有这个视频质量真的是太差了……

虽然但是，我也从来没有给这个视频很多的期望，毕竟饭得一口一口吃，路得一步一步走嘛，况且，我也没有把做视频来当做自己的主业，纯粹就是当做一种课外爱好。

## 2 - 初识Github

### 2.1 - 新的篇章

截止到2024年暑假之前，我对GitHub还是不那么熟悉的。

一方面是我没有写代码的需求，当时我还没有正式开始学编程等技术，会的也是一只半解；另一方面就是由于众所周知的原因，访问GitHub会很慢，甚至有时候连不上。当时有加速器，但是效果也不好，也没学会用梯子。

后来在我朋友的帮助下，我也是学会用梯子了（收敛。）

然后我就在暑假正式注册了我的第一个GitHub账号：

### 2.3 - 打造个人网站

熟悉GitHub的应该都知道，GitHub有一个网站托管的功能，叫做GitHub Pages，比如说我的用户名是 `ElofHew`，那么我只需要新建一个名叫 `ElofHew.github.io` 的仓库，然后上传一些静态网页必须的HTML等文件，再开启Pages部署，就可以通过在浏览器里打开这个URL，来访问我的网页了。

于是，在2024年的11月，我从零开始，自己手搓HTML，写出了一个最开始十分简陋的个人网站：（下面给的QQ空间动态图不是最初的版本）

![20260811-180449.jpg](https://img.danevan.top/image/pic/20260811-180449.jpg)

碰巧在这个时间点，AI Coding的概念刚刚出现，所以在当时，我也借助了AI来帮我写一些JavaScript代码，当时的HTML和CSS基本上都是手搓的。

而在如今AI Coding全面兴起的时代，我自然也是拿AI来给我的网站润色、美化了很多。如果要访问我的主站，可以直接在博客页面点击底下的 **主站** 按钮跳转，或访问：[www.danevan.top](https://www.danevan.top/)

在当时，我想给这个网站绑一个自定义的域名，就在阿里云上花了大概8块钱吧，买了一个 `.xyz` 的域名： `www.drevan.xyz`，当然 `.xyz` 域名是一个天坑，首年便宜续费贵，我记得当时如果要续费的话，好像得八九十块钱了，所以我索性直接换了一个 `.top` 域名，也就是现在的 `www.danevan.top`。`.top` 域名首年十几块，续费也就二十几块，相对来说还是可以接受的。
