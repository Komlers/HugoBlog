## 前情提要

在2025年暑假后，我们**全校**4栋教学楼的**教室大屏电脑**迎来了一波全面升级，一半换了希沃，一半换了科大讯飞智慧窗。

| 硬盘  | 希捷1T 7200转 机械  |
| 屏幕  | 1024x768 古董投影仪 |

>[!NOTE] 关于配置说明
>由于我混迹的两个教学楼都是讯飞的机子，故本文以讯飞为准。

整个高一学年，我年前当**电教委员**（中间选科后分班，名义上不是了），年后当**班长**（其实关于电脑的事一直都是我在搞），但都没对教室电脑有过什么~~非分之想~~，顶多就是给教室电脑优化性能、美化桌面、开发点实用小软件（比如：[随机抽取工具](https://github.com/ElofHew/RandomCallTool/)）什么的。

今年暑假过后，我们高一升高二，教学楼换到了高一楼对面的楼（上一届高三毕业的教学楼）。进入新教室，新的学年，新教室的电脑自然成为了我的把玩对象。

## 初见端倪

### 萨拉热窝事件

教室电脑上，有个东西很引人注目：**ToDesk**。

同时根据D盘文档、截图、录屏、照片等文件分析，我推断出这是**上一届班主任**留下来的圣遗物。当然账号肯定退登了，老师也不傻。

但是，这倒是提醒我了：我直接抽空把我的ToDesk账号登上去了，同时还装个了**网易UU远程**。这下，每天放学回到家远控班里电脑就成了我的“打卡任务”。

还有个同学，本文称为小D，他从高一就开始跟我一块摆弄班级电脑。看到我搞远控软件，也找我要了远控码，加入了我的队伍。（后来直接登上了我的UU远程号，更方便一些）

其实到这里只谈远控，不足以体现本文的主题，但不可否认的是，远控软件的发现，无疑是打通了我们的思路。

### 莱克星顿的枪声

后来，学校给所有老师的办公电脑来了一波换新，由老掉牙的**清华同方**一体机换为**联想异能者**一体机：

| 硬件  | 清华同方       | 联想异能者       |
| --- | ---------- | ----------- |
| CPU | i3-7100    | i5-12450H   |
| GPU | UHD核显      | UHD核显       |
| 内存  | 4G DDR3    | 16G DDR4    |
| 硬盘  | 1T西数机械     | 512G固态      |
| 屏幕  | 1080P 60Hz | 1080P 100Hz |
| 系统  | Windows10  | Windows11   |
| 评价  | 拉          | 666         |

>[!NOTE] 《OEM特供》
>i5-12450H 这U指定是有点说法的，你几乎能在**任何非消费者零售渠道**见到它……

英语老师叫我帮忙去给新电脑“开荒”的时候，我们班主任说她电脑上的学校监控客户端连不上了，**我就拿U盘把英语老师电脑上的监控客户端压缩包拷下来了**，打算给班主任装上去（注意这个要考），看看是不是客户端的问题。

给班主任装上后无果（后来她说是因为连同一个监控的人太多所以挤不进去，谁知道问题原因究竟是不是这个），**但是监控客户端程序仍然在我这里**。我就解压到了我们班里的电脑，输入IP、账号、密码，**真的登录上去了**！

学校的监控服务器是只能在学校内网（172.x.x.x）内连接的，所以我们班的电脑（172.18.34.117）就能正常连接。

>[!TIP] 关于学校配网
>在教室电脑里，对于有线网卡，如果IP和DNS都遵循**自动分配**，就连不上网（内/外网都不能），必须手动配置，比如我们班的：

| 项    | 值              |
| ---- | -------------- |
| 地址   | 172.18.34.117  |
| 子网掩码 | 255.255.255.0  |
| 网关   | 172.18.34.1    |
| DNS  | 211.137.191.26 |

## 深入探索

小D和我从此刻起，就对学校的网络体系展开了更深入的研究与探索。

在我们4楼中间的连廊旁边，有两个管道井，一个有电闸，一个有交换机。为了后文的叙述，后文称**有交换机的那个地方**为**电井**。

碰巧，电井的门没锁（和之前高一楼一样，不锁门），我们去里面看了一下，有两台H3C的交换机，还有两个平面集线器当作“中转”，每根网线上面都贴着标签，比如“4南4”，就是4楼南侧第4间教室的大屏电脑用的网线。

>[!NOTE] 关于IP地址
>上文讲过，我们班是 `172.18.34.117`；这一层楼南侧5个班的IP地址依次是：`116` / `117` / `118` / `119` / `120`。

所以，小D就提出了一个方案：

他从他仓库里拿一台独立的OPS小主机过来，扔到电井里，接上交换机，当作一台挂机设备，和教室电脑一样用UU远程/ToDesk远程控制连接，可用于当教室电脑的备份服务器、看学校监控等。

### 磨刀霍霍

所以，我们就展开了准备工作。经过分析，需要准备的东西有以下：

- **一台OPS小主机**：由小D提供，配置为，i3-4170+4G内存+128G固态。
- **一个HDMI欺骗器**：用于插在OPS上模拟显示器，否则可能会因为无输出信号而自动关机，由我购买（￥14）

此外，针对小主机，还需要进行如下配置：

- BIOS中打开WoL（Wake-On-LAN），用于远程开机，避免意外关机后开机麻烦的问题。
- 更换一个CR2032电池，不然CMOS设置无法保存。

首先，我们先对交换机进行了实验。

### 可乘之机

前文讲到过，连接到交换机的终端，必须手动分配静态IP地址，自动分配是连不上网的。

所以我拿了一个WinToGo环境，插在教室电脑上，启动到WTG。

我想，`172.18.34.x` 这个网段的IP应该没分完，所以我尝试手动写个 `172.18.34.191`，其他网关、子网掩码等和原环境一样。

| 项    | 值              |
| ---- | -------------- |
| 地址   | 172.18.34.191  |
| 子网掩码 | 255.255.255.0  |
| 网关   | 172.18.34.1    |
| DNS  | 211.137.191.26 |

结果就是，正常识别到了网络，并且能正常访问互联网，我们无疑是喜悦的。

>[!NOTE] 一个小插曲
>刚开始，我心急忘了配置DNS了，导致只能识别到网络，后来分析后我认为，交换机那边应该是没问题的，实装的时候记得填就行。

但我认为，交换机那边可能和网卡的MAC绑定了，所以究竟能不能行，还是存疑。

我们又去勘察了一下电井的环境，交换机上还有剩余的空闲接口，供电也没问题，所以万事俱备，只欠OPS了。

### 大刀阔斧

等到周末，小D把OPS带来了，我也就拿回家进行了一些准备工作：

- 拆机换电池
- 换硅脂
- 重装系统（我自己封装的Win10镜像，基于LTSC2021）
- 安装UU远程并登录账号

>[!NOTE] 令人头疼的插曲
>周六一下午，我都在跟BIOS死磕，原因是固件的UEFI启动支持太拉跨，老是卡在开机自检页面，最后忍无可忍，清CMOS并开启CSM，使用Legacy启动方式才得以进系统。

最后，我在家宽情况下，先把网卡预配置了一下：

| 项    | 值               |
| ---- | --------------- |
| 地址   | 172.18.34.199   |
| 子网掩码 | 255.255.255.0   |
| 网关   | 172.18.34.1     |
| DNS1 | 114.114.114.114 |
| DNS2 | 8.8.8.8         |

毕竟到学校就没有显示器了，万一连不上网那就真配不上网了。

同时，我还找了个USB小网卡当作备用的退路。

### 开动

周日下午返校，我把机器带回，准备正式实装。

我们又一次进入电井，看了一下交换机上，有个标着“32”的网口空闲，就直接找了根网线把它和OPS接一起了。

小D光是在那里调整位置和走线就花了不少时间，最终放在上面那台交换机上面。

万事俱备，开机。

我拿出手机（不要在意我为什么带手机），打开UU远程客户端，看到这台OPS的状态变为“在线”，我就知道，**我们赢了**。

我紧接着通过远控测试了一些功能，全都正常。包括WoL唤醒，也正常。

同网段访问教室电脑（172.18.34.117）和跨网段访问监控（172.16.254.254）都正常，但转念一想，老师电脑连的WiFi也是异网段，也能访问监控，所以也是意料之中。

## 未来打算

这台OPS小主机在未来打算用于以下用途：

- 辅助远控班级电脑
- 应急查看学校监控
- 搭建网络中转服务器，连通内网与外网
- 配置内网穿透，充分利用这台小主机
- 当作挂机机器（~~反正用的学校的电~~）

当然，具体能不能实现，包括合规等问题，还有待考虑，短期不会施行。

说实话，直接接交换机上就成功有点出乎预料，甚至考虑到的MAC地址绑定都没用。

我能想到的最合理的解释就是：

- 学校网管技术水平低（毕竟小县城普高）
- 没有陌生设备接入的防护
- 没考虑到会有人这样搞
- 有意为之
