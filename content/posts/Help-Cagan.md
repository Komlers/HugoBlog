CaGan服务器是一个Minecraft高版本**公益服务器**，当前服务器内有三种玩法：

### 子服务器

1. **原版生存服**：基于原版生存，同时适配生电玩法，服务端支持更多非原版特性（例如潜影盒堆叠、末影箱扩展等）。同时安装了很多实用插件（例如箱子商店、领地、传送等生存服务器标配插件）。
2. **粘液空岛服**：基于[粘液科技](https://slimefun-wiki.guizhanss.cn/Home/)+空岛生存玩法，可以在自己的空岛上发展一系列科技产业，扩展丰富你的空岛。
3. **小游戏服**：目前只有起床战争这一项玩法，这个不用多介绍了吧。

### 支持的版本

服务器为Java基岩互通服，支持以下版本：

**Java版**：1.18~最新版，支持正版账号、离线账号、外置登录（如LittleSkin）

**基岩版**：最新版，必须登录微软账号才能进服。

进服时请确保你用的是**正式版**，测试版和快照版本均不可进服。

若服务端版本有更新，服务器会同步更新服务端。

## 4 - 游玩优化

### 01 - 头衔系统

在**原版生存服**和**粘液空岛服**内，可以通过指令 `/prefix` 来自定义玩家头衔。

**用法**：`/prefix &xXXXX`

**解读**：在本服务器内，可以使用颜色代码来自定义头衔颜色。不同的，需要使用 `&` 替代 ` §`，例如：`&b（浅蓝色）` 等同于 `§b（浅蓝色）`。具体可以参考下面的颜色表：

![MCCOLOR.jpg](https://img.danevan.top/image/pic/MCCOLOR.jpg)

例如，我想修改我的头衔为浅蓝色的**Fedora**，可以输入指令：`/prefix &bFedora`。

设置头衔**完全免费**且**不限次数**，且在任何一个子服务器内（小游戏服除外，无头衔系统）设置好的头衔，在传送大厅、原版生存服和粘液空岛服内都能同步显示，无需多次修改。

### 02 - Home系统

服务器内置了设置家的功能，但不同的是，**设置家的数量和次数均无限制**，这就意味着你可以把sethome当做一个私人传送点的功能来使用。

**用法**：

- 设置新的家，名为xxx：`/sethome xxx`
- 传送到名为xxx的家：`/home xxx`
- 删除名为xxx的家：`/rmhome xxx` 或 `/delhome xxx`
- 将名为aaa的家重命名为bbb：`/renamehome aaa bbb`

在 `/sethome` 和 `/home` 的时候，如果不加名字，则默认**创建**或**传送**到名为 `home` 的家。

### 03 - 传送系统

在原版生存服中，内置了玩家间传送的功能：

**用法**：

- 传送到某人：`/tpa xxx` 或 `/tpask xxx`
- 让某人传送到我这里：`/tpahere xxx`
- 接受传送请求：`/tpaccept`
- 拒绝传送请求：`/tpdeny`（暂时不可用，置之不理或打字给对方说一下即可）

一个请求的有效时间为**120秒**，超过这个时间请求会过期。

### 04 - 切换皮肤

登录服务器后，服务器会自动根据你的ID查找对应的正版玩家皮肤。

而对于离线玩家和外置登录：

- 你用的ID碰巧有个正版玩家跟你一样，就会自动使用ta的皮肤
- 没有正版玩家跟你的ID一样，就会使用默认皮肤（通常是那个黑人）

对于基岩版玩家，情况暂未知，可能是直接从Xbox档案找皮肤，也可能是按你的玩家代号找Java版玩家的皮肤。

但是不必担心，服务器内置了切换皮肤功能（正版玩家也能用）。

**用法**：

- **切换皮肤**：`/skin playerID`，切换到正版玩家ID的皮肤，例如：`/skin Dream`，就会应用Dream的皮肤；`/skin Notch`，就会应用Notch的皮肤。
- **切换到URL皮肤**：`/skin url xxx`，从URL获取皮肤并应用（最适合离线/外置玩家），其中，URL需要是皮肤底图直链（可以将皮肤上传到[LittleSkin](https://littleskin.cn/)或在线图床）。

>[!NOTE]
> LittleSkin使用方法：
> 
> 1. 进入[LittleSkin官网](https://littleskin.cn/)，登录你的LittleSkin账号
> 2. 在皮肤库中，找到一个你喜欢的皮肤
> 3. 点击皮肤预览页面的**下载**按钮
> 4. 复制这个皮肤的**下载连接**（假设这个皮肤ID是144245）
> 5. 在游戏中使用指令 `/skin url https://littleskin.cn/raw/144245`
> 6. 皮肤应用成功！
> 
> 需要注意，LittleSkin的皮肤底图URL格式一般是 `https://littleskin.cn/raw/皮肤ID`。

- **清除皮肤（重置）**：`/skin clear`，适用于想要恢复原来的皮肤。

### 05 - 箱子商店

在原版生存服中，你可以创建箱子商店，用于玩家之间的交易。

**用法**：

- 创建箱子商店：手持你想要出售的物品，左键点击一下箱子，在聊天框里输入该物品的单价，回车，箱子商店就创建好了。

- 从箱子商店购买物品：右键箱子商店前的告示牌，在聊天框里输入你想要购买的数量，回车，即可购买物品。

### 06 - 世界商店

世界商店可以在箱子菜单中找到，用于**直接从服务器购买物品**或**直接出售物品**，可以理解为服务器银行。

>[!NOTE]
>即使世界商店可以很便捷的购买或卖掉物品，但可供交易的物品种类很少，且购买时价格较高，建议优先使用箱子商店与玩家之间进行直接交易。

### 07 - 金币系统

在原版生存服内，服务器内置了金币系统。

**金币用处**：金币可以用于购买物品、创建领地和玩家间支付。

**获取金币**：金币最通用的获取方法就是通过出售物品给世界商店，出售物品的价格也不同。

**支付金币**：在玩家之间可以通过 `/pay xxx ???` 指令来直接打钱到对方账户，例如我要打钱50000金币到 `Mr_lbrain`，就可以用指令 `/pay Mr_lbrain 50000` 打钱。

### 08 - 领地系统

在原版生存服内，服务器内置了领地系统。其中关于领地系统的高级功能非常多，具体可以到[Minecraft插件百科](https://mineplugin.org/Residence)查阅。

这里碍于篇幅，优先讲常用功能：

1. **创建领地**：使用木锄头，左键一个地方作为第一个选取点，右键另一个地方作为第二个选取点，确定选区后，用 `/res create xxx` 指令创建领地（xxx为领地名，支持中文，但不支持特殊符号）
2. **删除领地**：使用 `/res remove xxx` 指令删除领地（通常需要二次使用 `/res confirm` 来确认，或点击聊天框的 `确认删除` 按钮）。
3. **重命名领地**：使用 `/res rename aaa bbb` 指令，将名为aaa的领地重命名为bbb
4. **领地赠送**：使用 `/res give xxx somebody` 指令，将名为xxx的领地赠送给某人，例如，我用 `/res give DanEvan Mr_lbrain`，就将我的DanEvan领地送给了Mr_lbrain，且赠送后领地所有权就归他所有。
5. **领地公共权限**：使用 `/res set (xxx)` 指令，可以打开箱子菜单交互页面来设置领地公共权限（如果你身在这个名叫xxx的领地里面，就可以不加领地名，直接 `/res set`），其中对于每一项权限，左键启用，右键禁用，Shift+左键可以删除（调用服务器默认配置）。

>[!TIP]
>如果你不清楚某一项权限到底是什么作用，建议不要更改，保持默认即可。
>
>另外，如果你的领地只有你一个人使用的话，建议全部权限保持默认，无需更改。

6. **领地玩家权限**：使用 `/res pset (xxx) somebody` 指令，可以打开箱子菜单交互页面针对某人来设置领地个人权限。比如我要在名为DanEvan的领地内，针对玩家Mr_lbrain设置权限，就可以用 `/res pset DanEvan Mr_lbrain`。此外，如果你的某个领地需要多人同时使用，可以直接使用 `/res padd (xxx) somebody` 和 `/res pdel (xxx) somebody` 指令，批量添加/删除某人在领地内的常用权限（如container、use、build等），避免手动单独配置的麻烦。

>[!TIP]
>其实针对某一项权限，可以直接在聊天框里指定这一权限名设置。
>
>比如 `/res set DanEvan use false` 意思就是：将领地DanEvan的公共权限use设置为阻止；`/res pset DanEvan Mr_lbrain use true` 意思就是将Mr_lbrain在领地DanEvan内的个人权限use设置为允许。

7. **领地进出提示词**：使用 `/res message aaa enter xxx` 可以将领地aaa的进入提示词设置为xxx；使用 `/res message bbb leave xxx` 可以将领地bbb的离开提示词设置为xxx；使用 `/res message ccc remove` 可以将领地ccc的进出提示词重置为默认。

>[!TIP]
>如果不喜欢进出领地的时候有提示词，可以使用指令 `/res set xxx title false` 将领地xxx的提示词关闭。

8. **扩展领地**：首先确保你身处你要扩展的领地区域中，然后面向你要扩展的方向（必须是正方向，东南西北上下均可），使用 `/res expand ?` 指令，可以向这个方向扩展。例如：我要给我的DanEvan领地向正西方向扩展10格，就先站在DanEvan领地内，面朝西，使用 `/res expand 10` 即可。
9. **收缩领地**：对应的，可以在领地内使用 `/res contract ?` 指令收缩领地。与扩展不同的是，收缩领地应用的是玩家背对的那一边，而不是玩家面向的那一边。例如：我在一个10x10x10的领地内，面朝上，使用 `/res contract 5`，执行后该领地的底部边界会收缩5格（例如，原底部边界时y=50，执行后底部边界会变成y=55），体积变为10x5x10。

>[!TIP]
>如果你的领地体积过大，建议使用 `/res expand` 和 `/res contract` 来调整领地大小，省钱还省事。
>
>但如果你实在看不懂怎么搞，那我建议还是删了领地重新圈地吧。

10. **领地冲突**：一般来说，领地之间会有一个缓冲区，通常是以一个领地的边界向外数8格。在这个缓冲区内，其他玩家不能把这一部分的空间包括在自己的领地里，但自己的其他领地不受限制。（说人话就是：不同玩家之间的领地不能离太近，至少要隔8格，但是你自己的不同领地可以离很近，甚至可以紧挨着。）另外对于所有的领地，无论是不同玩家还是同一玩家，两个领地之间都不能重叠。
11. **子领地功能**：在已经存在的领地中，可以创建子领地来细分区域。先用木锄头按创建领地的操作**在父领地区域内**确定选点，再使用 `/res subzone xxx` 创建名为xxx的子领地，例如我在DanEvan领地中创建了名为Clever的子领地，那么这个子领地的实际名为 **DanEvan.Clever**。子领地可以正常设置权限和赠送等。需要注意的是，需要父领地开启了子领地功能才能使用（`/res set (xxx) subzone true`），且目前一个父领地中最多可以设置**30个**子领地。

>[!NOTE]
> 关于**费用**与**赔偿**
>
> - **创建领地**：以格为单位，每格0.02金币（例如10x10x10的领地，需要支付20金币）。
> - **扩展领地**：与创建领地费用相同，以格为单位，每格0.02金币。
> - **删除领地**：按照领地圈地总费用的50%进行赔偿。（例如：一个10x10x10的领地价值20金币，那么删除领地时会赔偿10金币）。
> - **收缩领地**：与删除领地赔偿标准相同，以格为单位，每格0.01金币。
>
> 其他操作基本上不涉及付费和赔偿，子领地功能也免费。

12. **设置领地传送点**：在开启领地传送功能后（`/res set (xxx) tp true`），默认传送点是这个领地的一角。要修改这个传送点，可以站在你想设置为传送到的位置，使用 `/res tpset` 指令设置当前位置为领地新传送点。

### 09 - 活死人功能

在原版生存服内，有一系列的花样动作可以使用，比如：

- `/lay`：可以原地躺下
- `/sit`：可以原地坐下
- `/crawl`：可以原地趴下
- `/spin`：可以原地转圈（类似于三叉戟+激流在空中转圈那种效果）

之所以叫活死人功能，是因为在使用这些花样动作的时候：

- 其他玩家在睡觉的时候可以直接忽略你的存在，跳过黑夜
- 你的实体碰撞箱与你的动作状态占用的空间不同
- 敌对生物无法察觉到你的存在，但并不能充当假人用于生电机器挂机

我的理解是：当你在使用这些花样动作的时候，你的“肉体”还在服务器，但“灵魂”已经不属于这个服务器了。

要想取消这些花样动作状态，可以连按两下左Shift（潜行）。

>[!NOTE]
>此外，对于服务器中的**楼梯**和**台阶**，**空手**（注意一定是空手）右键的时候可以直接坐上去。

### 10 - 其他常用指令

- `/back`：用于死亡后传送回死亡地点或上一个home
- `/tell xxx abc`：向某人私聊（xxx是玩家名，abc是说话内容）
- `/tell xxx`：（不加说话内容）进入与某人的私聊频道（在该模式下直接发送到公屏的消息只会发到这个人，若退出/恢复Global频道，请使用`/tell`。）
- `/rc`：加入到领地内的聊天频道（前提是该领地已启用领地聊天）

>[!TIP]
>即使私聊环境下，其他玩家看不到你们之间的对话，但服务器后台仍有消息记录，请勿使用私聊模式畅所欲言，请思考什么该说什么不该说后再发送。

### 11 - 对于MOD的使用

理论上，在原版生存服中，一些主流生电MOD均可使用，例如：

- 投影（Litematica）
- 投影打印机（Litematica Printer）
- 灵魂出窍（Tweakeroo、Freecam）

### 12 - VIP和奖励

在原版生存服中，拥有VIP制度（非充值获得，服务器是**公益服务器**，不是打钱就可以获得好处的）。

获得VIP有如下几种方法（可能具有时效性）：

- 发布宣传视频到[哔哩哔哩](https://www.bilibili.com/)
- 在服务器内建造大型有观赏价值的建筑（同时奖励金币）
- 拉新人加入服务器（你和新人均有VIP奖励）
- 参加服务器内的限时性活动（可能同时奖励金币）

**VIP可以干什么**：生存模式下**飞行**（使用 `/fly` 指令开启/关闭飞行）。

**VIP计时标准**：按正常时间流逝速度消耗时长。例如：2026年8月8日上午8点获得两天VIP，则2026年8月10日上午8点准时到期（无论实际在游戏中使用了多长时间）。
