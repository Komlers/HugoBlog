## 一、此乃何物

**随机抽取工具**，字面意思，就是一款有随机抽取功能的软件，主要有三个功能：

| 功能          | 用在什么场景                   |
| ----------- | ------------------------ |
| 🎲 **随机抽组** | 随机抽数字组（1-26）或字母组（A-Z）    |
| 👥 **随机抽人** | 从班级名单中随机抽若干名同学回答问题       |
| 🎯 **随机点名** | 名字像跑马灯一样快速跳动，点"停止"定格在某个人 |

![01](https://img.danevan.top/image/pic/261002/01.png)

另外，桌面上还会有一个**悬浮球**，点一下就能快速抽取，不用来回切换窗口。

## 二、下载与安装

### 下载

打开官方网站的下载页面：[https://rct.danevan.top/download](https://rct.danevan.top/download)，在下载页面选择一个下载方式：

- **蓝奏云网盘**（推荐）
- **夸克网盘**（备用）
- GitHub Releases（官方项目仓库）
- Gitee Releases（国内镜像仓库）

![01](https://img.danevan.top/image/pic/261002/08.png)

### 安装

1. 双击下载好的安装包（`.exe` 文件）
2. 如果 Windows 弹出"**Windows 已保护你的电脑**"提示：点击"**更多信息**" → "**仍要运行**"**（软件完全开源，保证没有病毒和恶意代码）**
3. 按提示完成安装即可（注意不要更改安装位置）

>[!TIP] 下载提示
>如果用 Edge 浏览器下载时提示"通常不会下载此文件"，点击提示右侧的"**…**" → "**保留**" → "**仍然保留**"。
>
>或者你也可以尝试一下 **命令行下载**，可以规避 Edge 浏览器的检测。

## 三、准备一份名单

抽人和点名都需要先准备一份名单。**最简单的方法：用记事本创建一个 txt 文本文件，每行写一个名字。**

```txt
张三
李四
王五
赵六
……
```

也可以用 Excel 做好名单后另存为 **CSV（逗号分隔）** 文件；

亦或是从 Excel 中复制名字那一列表格，直接在记事本中粘贴获得 txt 文本文件。

>[!NOTE] 名单加载限制
>最多 1000 个名字，每个名字不超过 20 个字符（点名显示会截断到 10 个字符），重复名字会自动合并（可选）。

还可以把名单存入"样本库"（推荐，一次导入长期使用）：

软件自带一个**样本库**，可以把常用的班级名单都存进去，以后直接选用，最多存 50 份。

1. 打开软件，点击顶部菜单 **文件 → 导入样本到库**（或按 `Ctrl+I`）
2. 选择你做好的名单文件
3. 给名单起个名字（比如【高三8班】；默认自动填充名单文件名）
4. 确定，名单导入成功

![09](https://img.danevan.top/image/pic/261002/09.png)

>[!TIP] 小提示
>如果你直接用"选择文件"打开了一份名单，但样本库是空的，软件会主动问你要不要顺便存进样本库，点"是"即可快捷导入第一个样本到库。

## 四、开始随机抽取

### 随机抽组

1. 点击顶部"**随机抽取**"选项卡
2. 在上方选择分组方式：
   - **数字（123）**：抽取 1、2、3……
   - **字母（ABC）**：抽取 A、B、C……
3. 设置**样本总数**（一共有多少组，比如 9 个组）
4. 设置**抽取数量**（要抽几个组，比如 3 个组）
5. 点击"**抽取**"按钮（或按 `Ctrl+Enter`）

抽取结果会立刻显示在历史记录侧边栏，并且发出弹窗提醒 / ClassIsland通知。

![02](https://img.danevan.top/image/pic/261002/02.png)

### 随机抽人

1. 在"**随机抽取**"选项卡中，把抽取模式切换为**抽人**
2. 加载名单（任选一种方式）：
   - 按 `Ctrl+Shift+O` 从**样本库**中选择（最常用）
   - 按 `Ctrl+O` 手动选择外部名单文件（TXT或CSV）
3. 设置**抽取数量**（要抽几个人，比如 3 个人）
4. 点击"**抽取**"按钮（或按 `Ctrl+Enter`）

和随机抽组一样，抽取结果会立刻显示在历史记录侧边栏，并且发出弹窗提醒 / ClassIsland通知。

![03](https://img.danevan.top/image/pic/261002/03.png)

>[!NOTE] 结果太多时怎么办
>一次抽取**超过 10 个人**时，提示窗口只显示前 10 个名字，软件会自动把**完整结果保存成一个网页文件（HTML）** 并用浏览器打开，查看完整名单即可。

### 保存抽取结果

- `Ctrl+S`：保存最新一次抽取结果
- `Ctrl+Shift+S`：把所有历史记录一次性全部保存

>[!TIP] 你还可以这样
>**历史记录**侧边栏中，每一次抽取记录都有【查看】和【保存】按钮，点击【保存】即可快速保存对应抽取结果。
>
>此外，随机抽取页面中也有【保存当前结果】按钮，顶部工具栏菜单里也有相关功能。

抽取结果保存文件为网页格式（HTML），默认保存在软件目录的 `data/result` 文件夹中，也可以在配置里改为保存到桌面【随机抽取结果】文件夹下

## 五、随机点名（跑马灯式）

1. 点击顶部"**随机点名**"选项卡（或按 `Ctrl+P`）
2. 在下拉框中选择样本库里的班级名单，点击"**加载**"
3. 选择点名方式：

| 按钮       | 说明                                       |
| -------- | ---------------------------------------- |
| **开始点名** | 名字开始快速跳动，点击"**停止**"定格；如果 10 秒内没点停止，会自动停下 |
| **自动点名** | 随机速度（1~3倍）、随机时长（2-3 秒），到时自动停下，无需手动操作     |

4. 停止后，被点到的名字会以大字显示在屏幕中央

![04](https://img.danevan.top/image/pic/261002/04.png)

你还可以设置为：让每个人都被**点到一次**（不放回模式）

1. 点击"**点名设置**"
2. 点名方式选择"**不放回式**"（被点到的同学会暂时移出名单，不会重复被点）
3. 设置**重置限度**（名单什么时候恢复原样）：
   - **完全**：所有人都点过一遍后才恢复（推荐）
   - **过半**：剩下不到一半人数时恢复
   - **自定义**：剩下指定人数时恢复

其他点名设置（通用）：
- **名字轮换速率**：0.5x～5.0x，数值越大轮换越快
- **点名前打乱名单顺序**：每次开始前先随机打乱

![10](https://img.danevan.top/image/pic/261002/10.png)

>[!NOTE] 关于点名结果
>点名结果直接以大字形式显示在界面上，**不会**弹出提示窗口。

## 六、桌面悬浮球（一键快抽）

软件启动后，桌面上会出现一个**圆形悬浮按钮**（默认显示），始终置顶在所有窗口之上。

### 左键立即抽取

左键单击悬浮球，立即执行一次预设的抽取操作（**默认抽 1 个人**），上课时点一下就出结果，不用打开主窗口。

### 右键设置预设

右键单击悬浮球，可以设置左键点一下时做什么：

- **抽取模式**：抽字母组 / 抽数字组 / 抽人
- **抽取数量**：一次抽 1～9 个
- **悬浮球大小**：小 / 中 / 大三档

当前生效的选项前面会有**勾选标记（√）**。

### 拖动位置

按住悬浮球拖到顺手的位置即可，软件会记住位置，下次启动还在那里。（拖动不会触发抽取，只有原地单击才会）

>[!TIP] 如何关闭悬浮球
>在主界面点击"**配置**" → "**桌面集成**"，取消勾选"**显示桌面悬浮球**"即可。

## 七、系统托盘（常驻后台）

开启托盘功能后（默认开启），点击窗口右上角的【×】**不会退出软件**，而是最小化到屏幕右下角任务栏的通知区域继续运行。

- **左键托盘图标**：重新打开主窗口
- **右键托盘图标**：显示主界面、打开配置、检测更新、显示/隐藏悬浮球、完全退出软件

>[!TIP] 禁用托盘功能
>如果关闭了托盘功能，点 × 就会直接退出软件。

## 八、常用设置在哪里

点击主界面的"**配置**"按钮（或按 `Ctrl+,`）打开配置窗口，常用设置：

| 你想做的事                    | 去哪里设置              |
| ------------------------ | ------------------ |
| 开机自动启动软件                 | 桌面集成 → 开机自启        |
| 启动后自动加载某个班的名单            | 基本设置 → 默认加载样本      |
| 自动保存每次抽取结果               | 基本设置 → 自动保存抽取结果    |
| 结果保存到桌面                  | 基本设置 → 结果保存位置      |
| 切换抽样模式（基本/智能/高级）         | 抽样设置               |
| 设置默认抽几组、抽几个人             | 抽样设置 → 默认值设定       |
| 关闭/开启悬浮球                 | 桌面集成 → 显示桌面悬浮球     |
| 关闭/开启托盘                  | 桌面集成 → 关闭窗口后保留系统托盘 |
| 关闭启动时的更新检测               | 更新设置               |
| 结果弹窗推送到教室大屏（ClassIsland） | 高级设置               |

![05](https://img.danevan.top/image/pic/261002/05.png)

>[!NOTE] 关于抽样设置
>程序内置三种抽样模式：**基本**、**智能**（默认）、**高级**。
>
>对于三大模式的讲解，可以查阅文档：[抽样模式详细讲解 - 随机抽取工具 帮助文档](https://rct.danevan.top/docs/1-5)；下面给个简要表格：

| 特性   | 基本抽样  | 智能抽样 | 高级抽样  |
| ---- | ----- | ---- | ----- |
| 记忆性  | 无     | 有    | 可选    |
| 公平性  | 均等    | 动态公平 | 按配置决定 |
| 可定制性 | 低     | 中    | 高     |
| 适用场景 | 一次性抽取 | 多次抽取 | 差异化概率 |

## 九、怎么更新软件

- **推荐方式**：软件启动时会自动检测新版本，检测到后按提示打开**更新程序**即可，会自动下载安装
- **手动检测更新**：**工具 → 检测更新** 或 **配置 → 更新设置 → 立即检测更新**
- 更新程序支持切换 **GitHub / Gitee 两个更新源**（国内建议选 Gitee），还可以勾选"**接收测试版更新**"提前体验新功能

![06](https://img.danevan.top/image/pic/261002/06.png)

>[!WARNING] 如果手动更新
>如果手动从官网下载安装包运行安装更新，那么**更新前请先关闭正在运行的主程序和更新程序**，否则会因为文件占用导致安装失败。（自动更新不必考虑此问题）

## 十、怎么卸载软件

打开软件目录中的 **卸载工具（remove.exe）**，提供三种模式：

| 模式         | 效果                         |
| ---------- | -------------------------- |
| **保留数据卸载** | 删除软件，但保留你的名单和配置等数据（换版本时可选） |
| **重置配置**   | 只清空配置和日志，软件保留              |
| **完全卸载**   | 删除软件和所有数据                  |

卸载时会同时清理 **开始菜单文件夹** 和 **桌面快捷方式**。

![07](https://img.danevan.top/image/pic/261002/07.png)

## 十二、常见问题

**Q：抽取数量能超过名单人数吗？**
A：不能，软件会自动限制为名单总人数。（哪有抽的比总数多的道理……）

**Q：抽取历史存在哪里？**
A：软件会自动把每次抽取按日期记录在 `data/history/` 文件夹中（每天一个文件），同时界面右侧也能看到。菜单 **日志 → 打开今日历史记录** 可快速查看。

**Q：关闭窗口后软件不见了？**
A：软件默认最小化到屏幕右下角的**系统托盘**继续运行，点击托盘图标即可还原；右键托盘图标选"退出"才能彻底关闭。

**Q：点名和抽人有什么区别？**
A：抽人是一次性给出若干个结果；点名是跑马灯跳动后由你（或自动）定格在一个人，互动感更强，更适合课堂提问。两者共用同一个样本库。

**Q：换电脑或迁移软件，名单怎么迁移？**
A：把软件目录 `data/rcplist/` 文件夹里的文件复制到新目录即可；或者直接保留原始的 txt 名单文件重新导入。（或直接迁移整个 `data` 文件夹）

**Q：软件运行出问题了怎么排查？**
A：按 `Ctrl+L` 或菜单 **日志 → 查看日志** 打开当天的运行日志，里面记录了详细的运行过程和报错信息。（如果看不懂可以 **问AI** 或 **提交反馈**）
